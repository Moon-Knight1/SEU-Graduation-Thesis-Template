Many enterprise project management workflows still rely on manual statistics, separate spreadsheets, and offline coordination, which makes it difficult to maintain a consistent view of project progress, quality issues, and operational data. This thesis addresses the upgrade of a digital operation platform used by an automotive electronics enterprise. The existing workflow suffers from fragmented project data, limited cross-module visibility, and inefficient issue tracking. To address these problems, this thesis extends the platform's company management and project management functions, so as to support project process control and operational data analysis in a more integrated manner.

The system is implemented with a B/S architecture. Spring Boot is used to build the back-end services, while the front end is developed as a single-page application. Based on an analysis of the enterprise's daily software project management workflow, this work extends four functional modules: department-to-BU work-hour distribution, project basic information management, defect management, and major issue management. Permission control and Feishu-based message notification are also incorporated. These functions support unified business data management, project quality issue tracking, operational statistics, and performance optimization for selected query scenarios.

The upgraded system has been deployed for internal use. It provides unified management of project basic information, quality issues, and defect data, and connects relevant workflow notifications to Feishu. In practical use, the system reduces the management cost caused by scattered data sources, improves the informatization level of enterprise project management, and provides better support for quality control and operational analysis.
