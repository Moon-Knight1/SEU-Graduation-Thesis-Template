As enterprise digitalization deepens, software project management is under pressure to move beyond task delivery and toward quality-oriented delivery. In enterprise software projects, however, project collaboration, quality tracking, and operational analysis still depend heavily on manual statistics, scattered spreadsheets, and online communication. Defect data is distributed across multiple platforms and lacks a unified view, while the discovery, root-cause analysis, and escalation of major issues are not yet supported by a standardized process.

To address these problems, this thesis designs and implements an upgrade of a digital operations platform for an automotive electronics enterprise, with the aim of improving project process control and operational data analysis. The system adopts a B/S architecture: the back end is built with Spring Boot and MySQL, and the front end is implemented as a Vue-based single-page application. Based on daily software project management workflows, this work extends four modules: department-to-BU (Business Unit) work-hour distribution, project basic information management, defect management, and major issue management. Together with permission control and Feishu message notification, these modules support unified business data management, project quality tracking, and operational statistics. In the defect management module, strategy and template method patterns are used to refactor the multi-source query interface, and the query performance bottleneck encountered during implementation is optimized. Performance tests show that, under large page offsets, the average response time of the defect deep-pagination interface is reduced from the ten-second level to the hundred-millisecond level. The system has been deployed for internal use and now supports unified management of project information, defect data, and major issues. Through Feishu-based quality alerts and issue notifications, it provides practical support for data integration and operational analysis in enterprise project management.
