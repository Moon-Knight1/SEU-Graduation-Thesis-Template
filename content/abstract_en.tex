In an automotive electronics enterprise, software project management is moving from task delivery toward stronger quality control. In daily operations, project collaboration, quality tracking, and operational analysis still rely on manual statistics, scattered spreadsheets, and online communication. Defect data is split across platforms, and managers lack a unified view of project health. Major issue discovery, cause analysis, and escalation are not yet standardized, weakening issue tracking and risk identification. This thesis upgrades the enterprise's digital operation platform to improve project process control and operational data analysis.

The system adopts a B/S architecture with separated front-end and back-end development. The back end is built on Spring Boot, the front end uses Vue to implement a single-page application, MySQL and Redis support the data layer, and MyBatis-Plus simplifies data access. According to the workflow of enterprise software project management, four modules are extended: department-to-BU work-hour distribution, project information management, defect management, and major issue management. Permission control and Feishu notifications support unified data management, quality issue tracking, and operational statistics.

Performance tests show that, with a large page offset, the average response time of the defect deep-pagination interface is reduced from around ten seconds to hundreds of milliseconds. For work-hour statistics, the SQL execution plan is improved from a full table scan to an index range scan. The system has been deployed inside the company, supporting unified management of project information, defect data, and major issues. Through Feishu-based quality warnings and issue notifications, it provides data integration and operational analysis support for enterprise project management.
